# Homebrew Tap for Tinkerdown

This is the official Homebrew tap for [tinkerdown](https://github.com/livetemplate/tinkerdown).

## Installation

```bash
brew tap livetemplate/tap
brew install tinkerdown
```

## Upgrade

```bash
brew update
brew upgrade tinkerdown
```

## Uninstall

```bash
brew uninstall tinkerdown
brew untap livetemplate/tap
```

## What is Tinkerdown?

Tinkerdown turns markdown into apps. Write markdown with interactive components and serve them as web applications.

For more information, visit the [main repository](https://github.com/livetemplate/tinkerdown).
